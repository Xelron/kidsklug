# KIdsklug – Gute Fragen machen klug.

Website für [kidsklug.de](https://kidsklug.de) (statische Seite auf GitHub Pages) und Marken-Dateien des YouTube-Kanals [@KIdsklug](https://www.youtube.com/@KIdsklug).

- `index.html`, `impressum.html`, `datenschutz.html`, `style.css`: die Website
- `img/`, `fonts/`: Fotos (Higgsfield), Logo-Ausschnitte, selbst gehostete Schriften (Nunito, Literata, OFL)
- `CNAME`: Domain für GitHub Pages
